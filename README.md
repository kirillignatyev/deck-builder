# deck-builder

Генератор PowerPoint-презентаций с дайджестом книжных новинок из Excel.

Создает титульный слайд и отдельный слайд для каждой книги с обложкой, авторами, названием, аннотацией, причинами купить, тегами и характеристиками издания.

## Требования

- Python `3.14` или новее.
- `uv` для установки зависимостей и запуска проекта.
- Интернет для загрузки обложек с CDN АСТ.
- Шрифт **IBM Plex Sans** на компьютере, где открывается презентация, если требуется отображение в соответствии с настройками шаблона. Шрифт не встраивается в PPTX.

## Установка

Для установки зависимостей приложения выполните в корне проекта:

```sh
uv sync --locked
```

Для разработки вместе с dev-зависимостями:

```sh
uv sync --locked --group dev
```

Основные зависимости проекта:

- `polars` и `fastexcel` — чтение Excel;
- `Pillow` — работа с изображениями;
- `python-pptx` — создание PowerPoint-презентаций;
- `Typer` — командный интерфейс.

Версии для воспроизводимой установки зафиксированы в `uv.lock`.

## Командная строка

После установки проекта доступна команда `deck-builder`.

Минимальный вызов:

```sh
uv run deck-builder data/input.xlsx output/output.pptx
```

Команда принимает два обязательных аргумента:

```text
INPUT_FILE
OUTPUT_FILE
```

Входной файл должен существовать, быть обычным файлом и быть доступен для чтения.

Входной и выходной пути не могут указывать на один и тот же файл.

## Пример

В каталоге [`examples/`](examples/) находятся пример исходной таблицы и сгенерированной из нее презентации:

- [`titles_digest.xlsx`](examples/input.xlsx) — пример входных данных;
- [`titles_digest.pptx`](examples/output.pptx) — результат генерации.

Презентацию можно воспроизвести командой:

```sh
uv run deck-builder \
  examples/input.xlsx \
  examples/output.pptx \
  --title "Книжные новинки" \
  --suptitle "Пример презентации" \
  --attribution "deck-builder"
```

Данные в примере являются демонстрационными и не содержат рабочую издательскую информацию.

### Параметры титульного слайда

По умолчанию используются:

```text
Заголовок:    ДАЙДЖЕСТ НОВИНОК
Подзаголовок: РЕДАКЦИИ «ЛИНГВА»
Подпись:      МЕСЯЦ ГОД
```

Их можно переопределить:

```sh
uv run deck-builder data/books.xlsx output/digest.pptx \
  --title "Книжные новинки" \
  --suptitle "Сентябрь 2026" \
  --attribution "Редакция «Лингва»"
```

Справка:

```sh
uv run deck-builder --help
```

Пути с пробелами заключайте в кавычки:

```sh
uv run deck-builder \
  "data/books september.xlsx" \
  "output/september digest.pptx"
```

После успешной сборки CLI выводит путь к созданному файлу:

```text
Сохранено: output/digest.pptx
```

### Коды завершения

Команда завершается:

- с кодом `0` при успешной генерации;
- с кодом `1`, если Excel не соответствует схеме либо произошла ошибка чтения, сборки, загрузки изображения или сохранения;
- с кодом `2` при ошибке аргументов CLI, например если входной файл отсутствует или входной и выходной файлы совпадают.

Ошибки приложения перехватываются на границе CLI и выводятся без traceback.

## Формат Excel

Одна строка соответствует одной книге.

Названия обязательных столбцов должны совпадать со схемой, включая пробелы и знаки препинания.

Порядок столбцов не важен. Дополнительные столбцы допускаются и при сборке игнорируются.

`TitlesDigest.from_excel()` использует `polars.read_excel()` с настройками по умолчанию. Выбор конкретного листа через публичный API `TitlesDigest` сейчас не предусмотрен.

| Обязательный столбец | Тип после загрузки | Пример |
| --- | --- | --- |
| `Код ном-ры` | Строка | `00123` |
| `ISBN` | Строка | `9781234567890` |
| `Наименование на обложку` | Строка | Книга о языке |
| `Авторы на обложку` | Строка | Иван Иванов |
| `Аннотация` | Строка | Описание книги |
| `Пять причин купить` | Строка | Причины и теги, см. ниже |
| `Серия` | Строка | Изучаем языки |
| `Формат` | Строка | `60x90/16` |
| `Продукция.Тип переплета` | Строка | `3` |
| `Кол-во стр` | `Int16` | `128` |
| `Красочность блока текста` | Строка | `1+1` |
| `Тираж` | `Int64` | `1000` |
| `Продукция.Возрастное ограничение` | Строка | `12+` |

### Код номенклатуры и ISBN

`Код ном-ры` и `ISBN` приводятся к строковому типу, но если Excel изначально хранит значение как число, уже потерянные ведущие нули восстановить невозможно.

Поэтому значения вроде:

```text
00123
```

следует хранить в Excel именно как текст.

### Тип переплета

Значение:

```text
3
```

при выводе преобразуется в:

```text
мягкая обложка
```

Остальные значения выводятся без преобразования.

## Причины и теги

Поле `Пять причин купить` содержит одновременно текст причин и теги.

Каждый элемент размещается на отдельной строке:

```text
1. Понятные объяснения
2. Практические задания
3. Ответы для самопроверки
4. Удобный формат
5. Подходит для самостоятельного изучения
#английский_язык
#самоучитель
```

Строки, которые после удаления начальных пробелов начинаются с `#`, считаются тегами.

При обработке:

```text
#английский_язык
```

превращается в:

```text
английский язык
```

То есть:

- символ `#` удаляется;
- пробелы по краям удаляются;
- `_` заменяются пробелами;
- строки с тегами удаляются из текста причин.

### Минимальное количество тегов

Для непустого значения `Пять причин купить` генератор обеспечивает наличие как минимум двух тегов.

Если тегов меньше двух, список дополняется:

```text
<не заполнен тег>
```

Например, при одном теге:

```text
#самоучитель
```

будут сформированы:

```text
самоучитель
<не заполнен тег>
```

Если поле `Пять причин купить` пустое, причины и список тегов остаются пустыми.

Количество самих причин не проверяется. Заголовок блока на слайде всегда:

```text
5 причин купить
```

## Проверка Excel

При загрузке выполняются две проверки:

1. наличие всех обязательных столбцов;
2. возможность строго привести каждый обязательный столбец к типу из схемы.

При отсутствии столбцов в stdout выводится диагностика вида:

```text
Отсутствуют обязательные столбцы: [...]
```

Если значения нельзя привести к нужным типам:

```text
Эти столбцы нельзя привести к нужному типу: ...
```

В обоих случаях `load_from_excel()` возвращает `None`, поэтому:

```python
digest = TitlesDigest.from_excel(...)
```

создает объект с:

```python
digest.df is None
```

При использовании Python API это состояние следует проверять до вызова `build()`:

```python
if digest.df is None:
    raise ValueError("Некорректная таблица")
```

Иначе `build()` все еще сможет создать титульный слайд без книжных слайдов.

Пустая таблица с корректной схемой также создает только титульный слайд.

Ошибки открытия или чтения Excel не преобразуются в `None`, а передаются вызывающему коду как исключения.

Валидация проверяет структуру и типы данных, но не их предметный смысл и не обязательность заполнения каждой ячейки.

Например, отсутствие значения там, где дальнейший код ожидает число, может привести к ошибке уже на этапе сборки презентации.

## Обложки

Обложка загружается по значению `Код ном-ры` с фиксированного CDN АСТ:

```text
https://cdn.ast.ru/v2/{item_code}/COVER/cover1.jpg
```

Например:

```text
https://cdn.ast.ru/v2/00123/COVER/cover1.jpg
```

По умолчанию сетевой тайм-аут составляет 10 секунд.

Результаты скачивания кешируются в памяти процесса через LRU-кеш максимум на 256 значений. Кешируется в том числе отсутствие изображения.

При обработанной сетевой ошибке вместо обложки создается заглушка:

```text
НЕТ ИЗОБРАЖЕНИЯ
```

К обрабатываемым ошибкам относятся сетевые ошибки, timeout и некорректный URL.

Если CDN вернул данные, которые не являются корректным изображением, Pillow может выбросить исключение при определении его размеров. Такое исключение не заменяется заглушкой автоматически и передается вызывающему коду.

### Размер обложки

Изображение вписывается в заданную область с сохранением исходных пропорций.

Растягивания изображения до полного размера контейнера не происходит.

## Построение презентации

`TitlesDigest` создается методом:

```python
TitlesDigest.from_excel("data/books.xlsx")
```

Объект содержит:

```python
digest.config
digest.deck
digest.df
```

Метод:

```python
digest.build(...)
```

изменяет внутренний объект `python-pptx Presentation` и возвращает тот же `TitlesDigest`, поэтому можно использовать цепочку вызовов:

```python
TitlesDigest.from_excel("data/books.xlsx").build(
    title_text="Книжные новинки",
    suptitle_text="Сентябрь 2026",
    attribution_text="Редакция «Лингва»",
).to_pptx("output/digest.pptx")
```

Однако при таком варианте невозможно предварительно проверить `df is None`, поэтому для данных из внешнего источника предпочтительнее отдельная проверка.

Повторный вызов `build()` для того же объекта не очищает презентацию, а добавляет еще один титульный слайд и еще один набор книжных слайдов.

Для новой презентации создавайте новый объект через `from_excel()`.

## Экспорт PPTX

Метод:

```python
digest.to_pptx("output/digest.pptx")
```

использует общий экспортер `deck_builder.io.export.to_pptx()`.

Экспортер:

- преобразует расширение результата в `.pptx`;
- создает отсутствующие родительские каталоги;
- сохраняет презентацию через `python-pptx`;
- перезаписывает существующий файл по тому же пути.

Метод принимает как строку, так и `pathlib.Path`:

```python
from pathlib import Path

digest.to_pptx(Path("output/digest.pptx"))
```

## Настройка оформления

Основной конфиг дайджеста находится в:

```text
src/deck_builder/configs/titles_digest.py
```

По умолчанию используются:

```text
Размер слайда: 254 × 143 мм
Шрифт:        IBM Plex Sans
```

`PresentationConfig` объединяет:

- ресурсы презентации;
- размер слайда;
- поля;
- типографику;
- цвета;
- позиции элементов титульного слайда;
- позиции элементов книжного слайда.

Логотип и иконка находятся в:

```text
src/deck_builder/assets/
```

Пути к ним определяются относительно установленного Python-пакета, поэтому запуск проекта не зависит от текущей рабочей директории.

### Создание измененной конфигурации

Конфигурационные dataclass-объекты неизменяемы (`frozen=True`).

Например, для замены шрифта:

```python
from dataclasses import replace

from deck_builder.builders.titles_digest import TitlesDigest

digest = TitlesDigest.from_excel("data/books.xlsx")

if digest.df is None:
    raise ValueError("Некорректная таблица")

config = replace(
    digest.config,
    typography=replace(
        digest.config.typography,
        font_family="Arial",
    ),
)

digest = replace(
    digest,
    config=config,
)

digest.build(
    title_text="Книжные новинки",
    suptitle_text="Сентябрь 2026",
    attribution_text="Редакция «Лингва»",
).to_pptx("output/titles_digest.pptx")
```

## Ограничения шаблона

Позиции основных элементов слайда фиксированы конфигурацией.

Текстовые блоки используют автоматическое увеличение высоты, но координаты следующих элементов при этом автоматически не пересчитываются.

Поэтому длинные:

- названия,
- аннотации,
- списки причин,
- теги

могут привести к пересечению элементов или выходу за предполагаемую область.

После генерации презентации рекомендуется проверить результат в PowerPoint или совместимом приложении.
